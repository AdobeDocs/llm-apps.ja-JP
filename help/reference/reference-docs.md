# アクションフィールドとウィジェットフィールド {#action-widget-configuration}

>[!IMPORTANT]
>
>[!DNL Adobe LLM Apps]は現在Betaにいます。
>
>ここに示す機能、ワークフロー、UIは、必ずしも製品の最終状態を表すものではありません。 Betaに参加するには、llm-apps-beta@adobe.comに電子メールを送信します。

このページを使用して、アクションエディターでフィールドを検索します。 完全な作成ジャーニーについては、[最初からアクションを作成する](/help/guides/create-action.md)を参照してください。

## アクションパラメーター

入力パラメーターは、LLM プラットフォームがアクションハンドラーに送信する値です。 モデルはユーザーのメッセージからそれらを抽出し、これらのフィールドにマッピングします。

| プロパティ | 説明 |
|----------|-------------|
| **名前** | パラメーター識別子（例：`category`、`query`） |
| **タイプ** | `String`、`Number`、`Integer`または`Boolean` |
| **説明** | 人が判読可能な説明：LLM プラットフォームは、これを使用して適切な価値を抽出します |
| **必須** | オンにした場合、モデルはアクションを呼び出す前にこのパラメーターを指定する必要があります |

### ファイルパラメーター

ファイルパラメーターは、アクションエディターで設定された入力フィールド名です。 ユーザーがファイルをアップロードすると、ホストはそれらの引数（通常は`download_url`と`file_id`を含む）のファイルオブジェクトを提供します。

## メタデータフィールド

### 基本情報

| フィールド | 必須 | 説明 |
|-------|----------|-------------|
| **アクション名** | はい | アクションの表示名（例：*製品を検索*） |
| **説明** | はい | アクションの内容の説明：LLM プラットフォームは、アクションを呼び出すタイミングを決定するためにこれを使用します |

作成後、エディターには不変の&#x200B;**コード識別子**&#x200B;も表示されます。 アクションをハンドラーリポジトリの`actions/<code-identifier>/index.js`にマッピングします。

### 注釈

アクションの動作を説明するオプションのヒント：

| 注釈 | 説明 |
|------------|-------------|
| **破壊的なヒント** | アクションは、データを変更または削除します |
| **Idempotent** | 同じ引数でアクションを複数回呼び出すと、同じ結果になります |
| **オープンワールドのヒント** | アクションは外部システムと相互作用します |
| **読み取り専用のヒント** | アクションはデータを読み取るだけで、書き込みはありません |

### OpenAI メタデータ

| フィールド | 最大長 | 説明 |
|-------|------------|-------------|
| **ステータス テキストの呼び出し** | 64文字 | アクションの実行中にLLM プラットフォームに表示されるメッセージ （例：*製品の読み込み…*） |
| **呼び出された状態のテキスト** | 64文字 | アクションが完了した後に表示されるメッセージ （例：*製品が読み込まれました…*） |
| **ウィジェットの説明** | 512文字 | `_meta["openai/widgetDescription"]`にマップします。モデルのレンダリング済みコンポーネントを要約し、繰り返しナレーションを減らします |

アクションの説明は、モデルがアクションを選択するタイミングを制御します。 ウィジェットの説明では、コンポーネントがレンダリング後に表示される内容を説明します。

### 視認性

| 切り替え | 説明 |
|--------|-------------|
| **AI モデルに公開** | アクションは、会話中にAI モデルによって呼び出すことができます |
| **アプリサーフェスでウィジェットとして表示** | アクションは、アプリ内のビジュアルウィジェットをレンダリングします |

### Analytics

| フィールド | 説明 |
|-------|-------------|
| **ユーザーインテントの収集** | 分析のアクションに至った会話の概要を収集します |

## ウィジェットフィールド

### ウィジェット情報

| フィールド | 説明 |
|-------|-------------|
| **タイプ** | ウィジェット技術 – 現在&#x200B;**[!UICONTROL EDS]** |
| **ウィジェットドメイン（サンドボックスオリジン）** | ウィジェットがホストされるオリジン。アプリごとに一意である必要があります |
| **境界線を好む** | オンにすると、ウィジェットはLLM プラットフォームの枠付きカード内でレンダリングされます |

### テンプレート URL

| フィールド | 説明 |
|-------|-------------|
| **[!UICONTROL スクリプト URL]** | EDS `scripts/aem-embed.js` エントリポイントのHTTPS URL。 同じEDS プロジェクト内のアクション間で共有 |
| **ウィジェット URL** | このアクションによってレンダリングされるEDS ページのHTTPS URL。 生成されたアクションは、これを自動的に設定します |

## CSP設定

コンテンツセキュリティポリシーは、ウィジェットのiframeが接続できる外部ドメインを制御します。 すべての外部ドメインを明示的に許可リストに加えるする必要があります。

| ディレクティブ | 説明 |
|-----------|-------------|
| **リソースドメイン** | 静的アセットのドメイン – 画像、フォント、スクリプト、スタイル |
| **ドメインの接続** | ウィジェットが`fetch`、`XHR`または`WebSocket`を介して連絡できるドメイン |
| **フレームドメイン** | ネストされたiframeではオリジンが許可され、トリガーではアプリのレビューがより厳しくなります。 |
| **リダイレクトドメイン** | `openExternal`個のリダイレクトリンク （[!DNL ChatGPT]固有）の信頼されたターゲット |
| **ベース URI ドメイン** | `base-uri` CSP ディレクティブ （MCP Apps SDKのみ、[!DNL ChatGPT]ではありません） |

## 権限

ウィジェットがアクセスできるハードウェアおよびブラウザーAPI。 これらはiframe権限ポリシーにマッピングされます。

| 権限 | 説明 |
|------------|-------------|
| **カメラ** | デバイスカメラへのアクセス |
| **マイク** | デバイスのマイクにアクセス |
| **位置情報** | ユーザーの場所へのアクセス |
| **クリップボード** | クリップボードの読み取りまたは書き込み |
