# アクションフィールドとウィジェットフィールド {#action-widget-configuration}

>[!IMPORTANT]
>
>[!DNL Adobe LLM Apps]は現在Betaにいます。
>
>ここに示す機能、ワークフロー、UIは、必ずしも製品の最終状態を表すものではありません。 Betaに参加するには、llm-apps-beta@adobe.comに電子メールを送信します。

このページを使用して、アクションエディターでフィールドを検索します。 作成手順については、[最初からアクションを作成する](/help/guides/create-action.md)を参照してください。

## 設定を見つける

**[!UICONTROL 新しいアクションを作成]** ダイアログには、**[!UICONTROL アクション]**&#x200B;と&#x200B;**[!UICONTROL ウィジェットメタデータ]**&#x200B;のタブがあります。

作成後、保存済みアクションエディターは3つのタブを使用します。

| タブ | 設定 |
|---|---|
| **[!UICONTROL LLM ウィジェットの詳細]** | ウィジェットタイプ、サンドボックスドメイン、ウィジェットの説明、テンプレート URL、およびCSP |
| **[!UICONTROL アクションの詳細]** | コード識別子、説明、入力パラメーター、および注釈、呼び出しステータス テキスト、表示を含む&#x200B;**[!UICONTROL LLM設定]** |
| **[!UICONTROL Analytics]** | ユーザーインテントの収集と手順 |

編集を保存するには、**[!UICONTROL 変更を保存]**&#x200B;を選択します。 生成されたアクションは、レビュー待ちのため、**[!UICONTROL レビュー済みとしてマーク]**&#x200B;されます。これは、生成されたプルリクエストも処理します。

## アクションパラメーター

入力パラメーターは、LLM プラットフォームがアクションハンドラーに送信する値です。 モデルはユーザーのメッセージから値を抽出し、設定されたパラメーターにマッピングします。

| プロパティ | 説明 |
|----------|-------------|
| **名前** | パラメーター識別子（例：`category`、`query`） |
| **種類** | `String`、`Number`、`Integer`または`Boolean` |
| **説明** | 人間が判読可能な説明：LLM プラットフォームは、説明を活用して適切な価値を引き出します |
| **必須** | オンにした場合、モデルはアクションを呼び出す前にこのパラメーターを指定する必要があります |

### ファイルパラメーター

ファイルパラメーターは、アクションエディターで設定された入力フィールド名です。 ユーザーがファイルをアップロードすると、ホストはそれらの引数（通常は`download_url`と`file_id`を含む）のファイルオブジェクトを提供します。

## メタデータフィールド

### 基本情報

| フィールド | 必須 | 説明 |
|-------|----------|-------------|
| **アクション名** | はい | アクションの表示名（例：*製品を検索*） |
| **説明** | はい | アクションの説明：LLM プラットフォームは、アクションを呼び出すタイミングを決定するために説明を使用します |

作成ダイアログには、アクション名から派生した不変の&#x200B;**コード識別子**&#x200B;がプレビューされます。 これはアプリ内で一意であり、小文字で始まり、小文字、数字、ハイフン、またはアンダースコアを使用して、最大63文字が含まれます。 アクションをハンドラーリポジトリの`actions/<code-identifier>/index.js`にマッピングします。

### 注釈

アクションの動作を説明するオプションのヒント：

| 注釈 | 説明 |
|------------|-------------|
| **破壊的なヒント** | アクションは、データを削除または上書きする場合があります |
| **Idempotent （同じ引数=余分な効果なし）** | 同じリクエストを繰り返しても、環境に追加の影響はありません。繰り返されたリクエストは、必ずしも同じデータを返すわけではありません |
| **オープンワールドのヒント** | アクションは外部システムと相互作用します |
| **読み取り専用のヒント** | アクションはデータを読み取るだけで、書き込みはありません |

### OpenAI メタデータ

| フィールド | 最大長 | 説明 |
|-------|------------|-------------|
| **ステータス テキストの呼び出し** | 64文字 | アクションの実行中にLLM プラットフォームに表示されるメッセージ （例：*製品の読み込み…*） |
| **呼び出された状態のテキスト** | 64文字 | アクションが完了した後に表示されるメッセージ （例：*製品が読み込まれました…*） |
| **ウィジェットの説明** | 512文字 | `_meta["openai/widgetDescription"]`にマップします。モデルのレンダリング済みコンポーネントを要約し、繰り返しナレーションを減らします |

アクションの説明は、モデルがアクションを選択するタイミングを制御します。 ウィジェットの説明では、コンポーネントがレンダリング後に表示される内容を説明します。

### 視認性

アクションのオンとオフを切り替えるには、アプリページで&#x200B;**[!UICONTROL 表示]** スイッチを使用します。 スイッチは、次のデプロイメントにアクションを含めるかどうかを制御します。 アクションエディターには個別のオン/オフスイッチはありません。

次のアクションエディター設定は、アプリレベルのオン/オフ状態ではなく、モデルとウィジェットの露出を制御します。

| 切り替え | 説明 |
|--------|-------------|
| **AI モデルに公開** | アクションは、会話中にAI モデルによって呼び出すことができます |
| **アプリサーフェスでウィジェットとして表示** | アクションは、アプリ内のビジュアルウィジェットをレンダリングします |

モデルとウィジェットの露出の設定は、ウィジェットタイプの選択に代わるものではありません。

### Analytics

| フィールド | 説明 |
|-------|-------------|
| **ユーザーインテントの収集** | デフォルトで有効になっています。 分析のアクションにつながった目標の匿名サマリーをリクエストします |
| **ユーザーインテントの説明** | 概要のリクエストに使用される命令（最大2,000文字）。 デフォルトでは、個人情報と機密情報は除外されています。 プライバシーポリシーに対するカスタマイズの確認 |

## ウィジェットフィールド

### ウィジェット情報

| フィールド | 説明 |
|-------|-------------|
| **種類/ ウィジェットの種類** | 作成ダイアログで、**[!UICONTROL Edge Delivery Services ブロック]**&#x200B;または&#x200B;**[!UICONTROL ウィジェットなし]**&#x200B;を選択します。 保存されたエディターは、テキストのみの選択肢にラベルを付けます&#x200B;**[!UICONTROL インタラクティブ UIがありません]** |
| **ウィジェットドメイン** | ホストが使用するサンドボックスの生成元。 UIは、アプリの提出に必要な情報とアプリごとに一意の情報を識別します。 これは、EDS ページの&#x200B;**ウィジェット URL**&#x200B;とは別です |
| **境界線を好む** | 境界付きコンテナをリクエストします。レンダリングはホストによって異なります。 作成ダイアログで使用可能 |

### テンプレート URL

| フィールド | 説明 |
|-------|-------------|
| **[!UICONTROL スクリプト URL]** | EDS `scripts/aem-embed.js` エントリポイントのHTTPS URL。 同じEDS プロジェクト内のアクション間で共有 |
| **ウィジェット URL** | アクションによってレンダリングされるEDS ページのHTTPS URL。 生成されたアクションは、URLを自動的に設定します |

## CSP設定

コンテンツセキュリティポリシーは、ウィジェットのiframeが接続できる外部ドメインを制御します。 すべての外部ドメインを明示的に許可リストに加えるする必要があります。

| ディレクティブ | 説明 |
|-----------|-------------|
| **リソースドメイン** | 静的アセットのドメイン – 画像、フォント、スクリプト、スタイル |
| **ドメインの接続** | ウィジェットが`fetch`、`XHR`または`WebSocket`を介して連絡できるドメイン |
| **フレームドメイン** | ネストされたiframeではオリジンが許可され、トリガーではアプリのレビューがより厳しくなります。 |
| **リダイレクトドメイン** | `openExternal`個のリダイレクトリンク （[!DNL ChatGPT]固有）の信頼されたターゲット |
| **ベース URI ドメイン** | `base-uri` CSP ディレクティブ （MCP Apps SDKのみ、[!DNL ChatGPT]ではありません） |

## 権限

ウィジェット権限は、ハードウェアおよびブラウザーAPIへのアクセスを管理します。 権限は、iframe権限ポリシーにマッピングされます。

作成ダイアログの&#x200B;**[!UICONTROL 権限（MCP固有）]**&#x200B;の下に権限コントロールが表示されます。 ウィジェットに必要な機能のみを付与します。ホストサポートとユーザーの同意も適用されます。

| 権限 | 説明 |
|------------|-------------|
| **カメラ** | デバイスカメラへのアクセス |
| **マイク** | デバイスのマイクにアクセス |
| **位置情報** | ユーザーの場所へのアクセス |
| **クリップボード** | クリップボードの読み取りまたは書き込み |
