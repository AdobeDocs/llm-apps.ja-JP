# LLM アプリを[!DNL Claude] コネクタとしてテストします {#test-in-claude}

>[!IMPORTANT]
>
>[!DNL Adobe LLM Apps]は現在Betaにいます。
>
>ここに示す機能、ワークフロー、UIは、必ずしも製品の最終状態を表すものではありません。 Betaに参加するには、llm-apps-beta@adobe.comに電子メールを送信します。

デプロイメント後、LLM アプリはMCP サーバーのURLを公開します。 このURLを[!DNL Claude]にカスタムコネクタとして追加し、生成されたアクションとウィジェットをテストします。

**このガイドでは、**&#x200B;展開されたアプリを[!DNL Claude] コネクタとして追加し、ログイン動作を選択し、会話でアクションとウィジェットをテストする方法について説明します。

公開アクションと保護アクションを含むアプリの場合、[!DNL Claude]は保護アクションを呼び出すまで延期ログインをサポートします。 アクションがすべて認証を必要とするアプリは、使用前にログインする必要があります。 [独自のID プロバイダーでエンドユーザーを認証する](/help/guides/authentication.md)を参照してください。

## プランの要件

リモート MCPを使用したカスタムコネクタは、無料、Pro、Max、Team、Enterprise プランで利用できます。 無料アカウントは、1つのカスタムコネクタをサポートしています。 グループ版およびエンタープライズ版では、メンバーが接続する前に、承認済みの所有者が組織のコネクタを追加します。 エンタープライズカスタムの役割は、その権限を付与することもできます。

プランと組織のコントロールについては、[Claudeの現在のカスタムコネクタの手順](https://claude.com/docs/connectors/custom/add-unlisted)を参照してください。 リモート MCP エンドポイントは、ローカルブラウザーだけでなく、Claudeのインフラストラクチャからアクセスできる必要があります。

## MCP サーバーのURLをコピー

[!DNL LLM Apps] に移動します。

1. アプリの詳細ページを開きます。
2. **[!UICONTROL アプリのテスト]**&#x200B;を検索します。
3. **[!UICONTROL ステージング環境]**&#x200B;で、**[!UICONTROL URLをコピー]**&#x200B;を選択します。

## カスタムコネクタの追加

1. [&#x200B; カスタマイズ/コネクタ &#x200B;](https://claude.ai/customize/connectors)を開きます。 組織全体のコネクタの場合、代わりに承認済み所有者が[組織設定> コネクタ &#x200B;](https://claude.ai/admin-settings/connectors)を開きます。
2. 組織フローの「**[!UICONTROL カスタムコネクタを追加]**」または「**[!UICONTROL 追加]** > **[!UICONTROL カスタム]** > **[!UICONTROL Web]**」を選択します。
3. 必要に応じてコネクタ名を入力し、HTTPS MCP サーバーの完全なURLを貼り付けます。
4. ダイアログに複数の手順がある場合は、**[!UICONTROL 続行]**&#x200B;を選択して、検出された認証設定を確認します。
   - 認証が無効になっている公開アプリの&#x200B;**[!UICONTROL ログインなし]**。
   - **[!UICONTROL 必要に応じてログインします]**。公開アクションと保護アクションを含むアプリ。
   - コネクタを使用する前に、**[!UICONTROL 今すぐサインインして]** ログインしてサインインをリクエストしてください。
5. OAuthの場合は、ID プロバイダーでサポートされているクライアント ID メソッドを選択します。 事前登録済みのクライアントを使用する場合は、その詳細をURLやアクションメタデータではなく、コネクタのOAuth設定にのみ入力します。
6. 「**[!UICONTROL 追加]**」を選択します。 組織コネクタの場合、各メンバーは、自分のコネクタリストから&#x200B;**[!UICONTROL Connect]**&#x200B;を選択します。

**[!UICONTROL 詳細設定]**&#x200B;を含む単一の画面ダイアログを表示するアカウントもあれば、マルチステップのフローを表示するアカウントもあります。 レイアウトが異なる場合は、[現在のプラットフォーム手順](https://claude.com/docs/connectors/custom/add-unlisted#choose-authentication-settings)を使用します。

>[!NOTE]
>
>信頼できる開発者からのコネクタのみを使用してください。 Anthropicは、開発者が利用できるツールを制御したり、それらのツールが意図したとおりに動作するか、変更されないことを保証したりしません。

## 生成されたツールを許可する

[!DNL Claude]は、コネクタページの&#x200B;**[!UICONTROL ツール権限]**&#x200B;の下に生成された各アクションを一覧表示します。 新しいツールはデフォルトで&#x200B;**[!UICONTROL 承認が必要]**&#x200B;で、テスト中にすべての呼び出しを承認するよう求められます。

データを変更するアクションや、機密性の高い操作を実行するアクションに対して、承認プロンプトを有効のままにします。 テストに適切な場合は、特定の信頼できる低リスクのアクションに対してのみ&#x200B;**[!UICONTROL Always allow]**&#x200B;を使用します。

## コネクタのテスト

1. 新しいチャットを開始します。
2. メッセージボックスで&#x200B;**+**&#x200B;を選択し（または`/`と入力）、**[!UICONTROL コネクタ]**&#x200B;にカーソルを合わせ、この会話に追加したコネクタをオンにします。
3. 生成されたアクションのいずれかに一致する質問をしてください。 例：*コーヒーを見せてください。*

次のことを確認します。

- [!DNL Claude]が期待されるアクションを呼び出します。
- ウィジェットには、想定されるサンプルデータが表示されます。
- テキスト応答はウィジェットと一致します。
- ウィジェットのコントロールが期待どおりに動作します。

混合認証の場合は、まずログインせずに公開アクションを呼び出します。 次に、保護されたアクションを呼び出し、サインインプロンプトを完了し、後で同じリクエストが成功することを確認します。 欠落している権限や無効な入力もテストします。

アプリを変更した後、影響を受けるテストを再デプロイして繰り返します。 コネクタの保存された認証設定を変更する必要がある場合は、[!DNL Claude]でコネクタを削除して再度追加する必要がある場合があります。
