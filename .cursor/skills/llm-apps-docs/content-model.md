# コンテンツモデルと用語

## コンテンツタイプ

### チュートリアル

ひとつのジャーニーを通じて、新規ユーザーにアプローチ。

- 結果と前提条件を提示する：
- 1つのサンプルアプリと1つのシーケンスを使用します。
- 各ステップで必要な概念のみを説明しましょう。
- 最終目標を達成し、次のステップを明確化する。

プライマリチュートリアル：`help/guides/create-app.md`。

### コンセプト

プロシージャまたはフィールドカタログになることなく、パーツがどのように関連付けられるかを説明します。

- メンタルモデルと所有権の境界に注目する：
- 理解を深めるには、小さな図を使います。
- チュートリアル、ハウツーガイド、リファレンスへのリンク。

### チュートリアルガイド

情報に精通したユーザーが1つのタスクを完了するのに役立ちます。

- 望ましい結果から始めます。
- タスクに固有の前提条件のみを含めます。
- 推奨パスを1つ選択します。
- すべてのフィールドのリファレンスへのリンク。

例：最初からアクションを作成する、ウィジェットをカスタマイズする、EDS プロジェクトを取り込む、デプロイ、テストする。

### 参照

ユーザーが作業中に参照する事実に関する情報を提供します。

- 商品またはコードのサーフェス別に整理します。
- すべてのフィールド、契約、コマンド、制限、ステータスを正確に定義します。
- チュートリアルのナレーションと繰り返し例は避けます。

### トラブルシューティング

観察できる症状から始まります。

- 考えられる原因の特定：
- 安全な診断手順の提供：
- 認証情報や機密ログの開示をユーザーに依頼することは避けましょう。

## 正規用語

- **Adobe LLM Apps** – 最初の言及での完全な製品名。
- **LLM アプリ** – 製品によって管理される1つのアプリ。
- **アプリを作成** — アプリ作成ダイアログのUI セクション。
- **アプリを自動的にビルド** – 正確なチェックボックスラベル。
- **アクション** — LLM プラットフォームに公開される機能。
- **アクションメタデータ** — LLM アプリによって保存された名前、説明、スキーマ、注釈、表示、ウィジェット設定。
- **アクションハンドラー** — ハンドラーリポジトリ内のサーバーサイド関数。
- **ハンドラーリポジトリ** — ハンドラーとテストを含むリポジトリ。 UI ラベル **Boilerplate Repository**&#x200B;は、そのコントロールを記述する場合にのみ使用してください。
- **EDS リポジトリ** — ウィジェットブロックとコンテンツを含むリポジトリ。
- **Widget** — LLM プラットフォームでレンダリングされたビジュアル応答。
- **MCP サーバーのURL** — デプロイされたエンドポイントがLLM プラットフォームに登録されました。
- **ChatGPT プラグイン** — MCP サーバーのURLから作成されたChatGPT統合。
- **ステージング**&#x200B;および&#x200B;**実稼動** — デプロイメント環境。

MCP プロトコルの詳細を説明しない限り、ユーザー向けProseで「ツール」と「アクション」を切り替えないでください。

この製品はプラットフォームに依存しません。そのMCP サーバーは、ChatGPTだけでなく、サポートされている任意のLLM プラットフォームで動作します。 一般的または例示的な請求には、「ChatGPTなどのサポートされているLLM プラットフォーム」（または類似）を使用します。 今日、ChatGPT固有のコンテンツでのみChatGPTという名前を付けます。ChatGPTのテスト ガイド、その直接クロスリンク、ChatGPT固有のリファレンスまたはトラブルシューティング コンテンツです。

## リーダージャーニーの提案

1. 概要と前提条件。
2. アプリを自動的に作成。
3. 生成されたアクションを確認します。
4. ChatGPT プラグインをステージングしてテストします。
5. 生成されたハンドラーとウィジェットをカスタマイズする。
6. カスタマイズしたアプリを実稼動環境にデプロイします。

ゼロからアクションを作成し、EDS プロジェクトを導入することは、デフォルトの初回ジャーニーではなく、高度なブランチです。
